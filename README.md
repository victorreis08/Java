# Pomodoro Timer (Java)

Um timer baseado na técnica Pomodoro desenvolvido em Java para auxiliar na produtividade e gerenciamento de tempo.

## Funcionalidades

- Iniciar e pausar o timer
- Contagem regressiva de 25 minutos (Pomodoro)
- Intervalos curtos de 5 minutos
- Notificação ao término do tempo
- Interface

## Tecnologias

- Java
- Swing

## Como executar

1. Clone o repositório:
   git clone https://github.com/seu-usuario/pomodoro-timer

2. Acesse a pasta do projeto:
   cd pomodoro-timer

3. Compile:
   javac Main.java

4. Execute:
   java Main
